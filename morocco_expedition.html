The Brief

The home page is now the command deck.

This page is intentionally separate from expedition mechanics. It introduces the world, sets the tone, and routes players into the correct HTML experience for the expedition they choose.

What this page now does

It provides a single, visually distinctive starting point for the whole series. The voice is more editorial and cinematic, the navigation is clear, and the moving constellation field gives the landing page a distinct identity from the in-game screens.

Single front door All expedition versions are selected here first.
Dedicated links Each card opens its own expedition HTML file directly.
Brand continuity Shared typography and dark-glass treatment keep it aligned with the existing expedition style.

Visual direction

The page blends a premium expedition editorial feel with a cosmic field-screen aesthetic: gold accents, atmospheric imagery, restrained glass surfaces, and a responsive star map that subtly reacts to movement.

National Geographic influence Serif headlines, documentary tone, and terrain-led imagery.
Current brand style Dark void background, luminous interface details, and expedition naming language.
